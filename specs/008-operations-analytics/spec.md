# 008 经营数据、活动回传与复盘

## 目标

在不修改现有前端和 Agent 调度结构的前提下，增加订单级经营数据导入、统一指标计算、活动版本校验、可重复模拟回传和描述性复盘。

## 功能要求

- UTF-8 CSV 必须先预览再确认；按品牌、工作空间和业务键幂等去重。
- 支持团队 `products.csv`、`costs.csv`、`orders.csv` 中文表头；`products.csv` 只建立经营 SKU 映射，产品价格/卖点仍以 `产品知识库.csv` 为唯一来源；经营元金额转换为整数分存储。
- Git 只保存权威源数据和生成代码；看板派生 CSV/JSON 写入 `.local-data` 或测试临时目录，不进入版本库。
- 空值保持未知；任何贡献指标在成本或收入不完整时返回 `null` 和缺失计数。
- 看板 API 与 Agent 销量工具复用同一个订单级计算函数。
- 活动模拟必须绑定已批准且未失效的 Agent 策略版本；优惠变化必须重新审批。
- 模拟场景支持稳定、销量下降、高成本、活动未达预期，随机种子决定可重复结果。
- 复盘分开返回历史基线、活动预期、实际回传，明确不是严格因果归因。

## 验收

- 两天案例计算出预期增量 `+4000` 分、实际增量 `-16200` 分。
- 重复导入不放大汇总；跨品牌不可读；合成标识全链路保留。
- 18 元售价、15 元成本、第二杯半价返回每组 `-300` 分并阻断。
