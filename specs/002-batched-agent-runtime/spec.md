# 批量澄清、原生恢复与工作区边界
2026-11-18；用户已授权逐项实施，最后确认本轮不发布公网。

## 用户故事与验收
US1/P1: 独立问题批次。FR-001 同批最多3个问题，日期区间算一题，每题稳定ID；回答两题后只保留必要剩余问题，刷新不丢失。
FR-002 所有回答在服务器校验；过期批次/版本返回409，无副作用；选项集中提交一次，可自然语言回答多项；事实题不猜测值。
US2/P1: 对话推进。FR-003 有附件时仍能询问原因、说不知道、改目标和暂存资料，不被强制填旧任务字段；部分资料不能自动确认为事实。
FR-004 先聊天再上传保留同一任务及用户表达条件，清除模拟商品/成本/结果；确认后继续原目标。
FR-005 页面仅一个自由输入区；当前问题组不重复正文，旧资料折叠；附件编辑有保存校验路径；显示任务摘要和依据。
FR-009 多项自然语言补充须逐项核对字段；模型返回不完整提取结构时限定一次修复，未提及不能清空历史值。真实抽验发现的遗漏必须记录并回归，不能仅以离线解析通过作为验收。
US3/P1: 原生中断。FR-006 LangGraph interrupt暂停问题批次/策略确认，同thread Command恢复；等待刷新和服务重启仍可继续。恢复不重复之前工具调用，真实写操作保留版本和幂等检查。
US4/P1: 隔离。FR-007 session模式下身份来自后端登录会话；任务/品牌/文件/运行结果/记忆按workspace隔离。多人前禁止启动共享归并迁移。默认本机兼容。
US5/P2: 部署准备。FR-008 PostgreSQL业务库与checkpointer可配置；提供只向空目标迁移的工具、备份恢复说明、容器启动与健康检查。本轮不发布公网，不声称未运行的Postgres已验证。
收尾验收：本机启动器必须将业务数据和图状态同时放在指定runtime，不得继承远端checkpointer地址。实际停止/重启独立服务以及恢复整套本地快照后，原问题ID、版本、已收集条件须保留。

## 成功标准
独立3题一批、部分回答、过期提交、未知/改目标、上传继承、wait checkpoint恢复、两工作区越权拒绝有自动化证据；浏览器验证唯一输入区和批次提交。
