# 品牌对话建档与四类任务
2026-11-18，用户已同意实施；保持本地开发，不修改登录方案，不发布或推送。

FR-001 新会话默认无品牌事实，Agent引导上传品牌介绍/菜单/商品说明，也接受对话资料。明确选择演示才使用模拟数据。建档后继续上传前的任务。
FR-002 区分brand_setup、content、unit_economics、campaign四类任务；普通问答不强制填活动表。建档只要求品牌名/介绍，已有商品保留名称/卖点必填，价格在测算时必填。普通文案不问成本/日期/预算；单位测算不问平台/日期/销量；活动才按roi_mode收集依赖。
FR-003 商品增加规格及价格确认时间；同名多规格不自动合并。缺资料可暂存，确认资料与批准活动分离。
FR-004 每次资料确认保存原文件/版本、用户补充与编辑、确认时间、旧新值；冲突必须展示并明确确认，不静默覆盖。来源无法逐字匹配时不得伪造引用。
FR-005 本次主题/目标/受众/约束保存在任务，不自动成为长期品牌记忆。固定单门店自提；成本为食材/包材等变动成本，不等于净利润。未知最低贡献可明确选择只展示收益，不做达标判断。
FR-006 第二杯优惠的总活动收入使用用户给定的优惠配对组数，剩余杯数原价；2*组数<=总杯数。未知参与情况不自动全配对，可仅看单位收益。成本缺失不承诺可行，销量/基线缺失不输出ROI。
FR-007 普通文案和活动文案自动归档到统一作品管理，关联任务/品牌/策略/版本/来源；修改版本保留，失效同步。旧管理入口不能覆盖Agent作品的受控内容。可返回原对话。
FR-008 保留暖色页面；当前任务/品牌/等待原因/资料状态可见。新品牌用对话与上传引导，不以创建品牌表单为主入口。

验收：无模拟污染、四路径不同缺项、品牌无商品可建档、价格缺失普通文案可生成、同名规格、冲突拒绝及确认、优惠组数计算及非法输入、作品互通/越权、原策略确认与重启回归。
后置：新登录/角色、多门店、图片视频闭环、实际活动因果归因；不声称本轮实现。
