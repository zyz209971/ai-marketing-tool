# Validation Quickstart

确认方案后使用隔离离线运行库测试，保留第一轮本地数据及服务。

1. 新建品牌对话，粘贴用户OFF-01原句，检查名称/介绍/风格已提取；定位未提供保持空，资料仍需确认。
2. 确认测试商品18元，发送OFF-02原句，检查无需日期预算，只展示27元收入、16元变动成本、11元贡献收益。
3. 另开同路径仅缺成本的对话，回答“单杯变动成本：8元。”，应继续计算，不重复追问。
4. 先生成小红书普通文案，再指定标题“桂花遇见乌龙，日常一杯茶”；核对正文不变，复制与历史结果一致；相同标题不增加版本，不支持的指令不提示成功。
5. 检查该整句修改要求没有成为新的风格候选；不点击保存时长期记忆不增加。

后端分模块及前端检查按AGENTS执行，validation.md记录实际结果、截图和未测项；真实模型质量不在通过项。待人工验收前记录tree，不提交。
