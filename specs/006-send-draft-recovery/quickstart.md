# Validation Quickstart

前置：按AGENTS配置离线隔离环境，真实模型和Embedding关闭。

使用隔离的离线测试运行库，不破坏用户验收库。先输入普通消息并模拟本地提交异常/拒绝，查看文字仍在；恢复后重试一次。再模拟服务端已接收但响应丢失，核查相同操作只有一个run；模拟轮询失败时应查询原run，不自动重发。刷新、切页、有效问题选项和新草稿逐项复验。

自动检查：从仓库根目录运行 node --test frontend/tests/*.test.mjs；backend中各tests/test_*.py以独立pytest进程执行。新增测试名称在实现阶段确定，不把此处描述当已存在脚本。人工验收与自动结果分开记录，用户未通过前不得提交。
