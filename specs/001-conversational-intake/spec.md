# 对话补充、知识复用与记忆边界
状态：实现与验收中；范围：本地单工作区。2026-11-18

## 用户故事与验收
### US1 / P1 按当前任务补充并继续
用户上传不完整资料或提出营销需求，看到需要回答的具体问题、原因与合法选项，可选择或自由填写。
- FR-001 建档沿用现有模板；营销策略根据当前 roi_mode 检查数据依赖；单位收益不要求历史销量。普通问答不得自动生成补全任务。
- FR-002 每次待回答问题具有唯一 ID、关联任务、字段和选项；刷新页面后保留。
- FR-003 Given 旧问题被替换，When 提交旧 ID 或旧 revision，Then 返回 409 且不修改资料。
- FR-004 回答后保留此前资料，重新检查缺项；填完资料仍须用户确认入库。策略确认仍用原版本化入口。
- FR-005 用户未知的成本不提供虚构金额选项；预算/实际支出/销量假设严格分开。
### US2 / P1 旧知识库参与新文案
- FR-006 复用旧营销案例索引，不覆盖历史库。案例不可成为本品牌产品事实。
- FR-007 新文案保存品牌来源与营销参考来源；案例库缺失/无命中/失败不伪装成功。
- FR-008 确认后以审核文本更新索引；embedding 不可用时保留关键词检索并记录状态。
### US3 / P1 明确长期记忆
- FR-009 已确认品牌偏好跨任务读取；当前任务语气覆盖默认长期语气。
- FR-010 普通对话不自动保存长期偏好；用户点击明确保存操作后写入，记录来源任务消息。
- FR-011 已有品牌记忆编辑和删除仍有效；不跨品牌检索。
