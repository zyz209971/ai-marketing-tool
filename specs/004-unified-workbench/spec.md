# 统一营销工作台与全流程数据准备
2026-11-18；用户已授权执行上一轮 UI 方案，同时要求指导完整业务所需数据。

FR-001 网站首页默认是 Agent 对话。固定侧栏包含与 Agent 对话、品牌资料、产品库、营销创作记录、对话记录；保持同一页面框架。
FR-002 对话采用左导航/中对话/右上下文三栏；暖白、浅杏、橙棕、细线卡片。新对话有欢迎语；已有对话突出内容。管理页占用全部内容宽度；窄屏右栏折叠。
FR-003 统一品牌选择。已有对话品牌不可因浏览其他品牌而改写；从商品进入新对话携带已选商品。切页保留未发送消息与待答问题；执行时允许查看管理页面，禁止对同一任务重复提交。
FR-004 品牌、商品、作品复用现有服务与管理功能。作品记录和对话记录分开；Agent 作品可回原对话，旧作品保留查看/编辑入口。只把已有四路径做成快捷任务，不假装支持新优惠或视频闭环。
FR-005 路由支持刷新、返回、直接打开任务，兼容 agent.html?task=旧ID。对话列表支持品牌、关键词、分页，显示实际状态。切换页面不得因异步响应回跳。
FR-006 右栏仅展示真实品牌事实、当前任务状态、快捷任务和近期记录。新品牌为空态，未确认事实不展示为已知。设置保留；不新增头像账户或无功能通知。
FR-007 交付数据准备指南及虚构样例，覆盖上传→解析→补充→确认→经营数据→策略情景→批准→文案→局部修改。列清当前支持与后置营销手段、字段单位、来源和验收值。

后置：新登录/公网发布、React迁移、删除对话、任意Excel自动导入、优惠券/满减/组合套餐/积分会员计算、图片视频生产闭环。
