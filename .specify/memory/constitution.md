# BrandPilot 项目约束
版本 1.0.0 · 2026-11-18

1. 保留现有 FastAPI、LangGraph；前端按用户2026-11-18确认的统一暖色工作台改造，复用已有管理与对话逻辑，不覆盖队友其他工作。
2. 商品事实必须来自用户确认的品牌资料。营销案例只作为写法参考；经营数字由结构化工具计算。
3. 模型提取意图、选择工具和表达问题；后端检查必填字段、版本、成本与策略审批。未知不等于零。
4. 对话补充持久化；长期偏好需要用户明确确认，可修改和删除。任务偏好不能自动写为长期记忆。
5. 生成涉及交易条件的活动文案必须绑定已批准、未失效的策略。变更优惠、成本、商品或数据版本需重新测算确认。普通品牌/商品文案按独立任务生成，不强制成本与ROI，不得自行添加优惠承诺。
6. 密钥只读后端私有环境；数据和本地上传不得进入 Git。保持本机访问限制，完成身份隔离后才考虑公网。
7. 每个增量功能需 spec、plan、tasks 与验收证据。失败、未测和后置项如实记录。
