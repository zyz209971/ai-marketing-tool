# 本轮实现：品牌对话建档与四类任务

## 已实现

1. 新会话默认引导建档，只有明确选择模拟门店才使用演示数据。
2. 上传或对话整理资料，最多三题一起补充，预览确认入库后继续原任务。
3. 区分建档、普通文案、单位优惠、活动策略四条路径，按当前任务追问。
4. 商品支持规格和价格确认时间；同名多规格需消歧，未知价格允许后补。
5. Agent 资料预览显示新旧差异与字段来源；接受差异后入库，确认事件与事实在同一事务保存。
6. 第二杯活动测算使用明确参与组数，缺失时不按总量自动配对。
7. 文案自动归档到原作品管理，保留修改版本、策略/来源关联；可回到原对话。资料变更后旧作品显示历史版本。

## 本地体验

入口：http://127.0.0.1:8021/agent.html 。新建对话后选择“新品牌：通过对话和上传建档”，避免继续旧模拟会话。

可以先上传下面内容的 TXT，故意不写价格：

```text
品牌名称：山茶小站（测试品牌）
品牌介绍：面向大学生的校园茶饮品牌
产品名称：桂花鲜奶茶
规格：500ml
卖点：桂花香气与鲜奶风味
```

确认后依次体验：

- “帮我写一篇小红书的桂花鲜奶茶介绍，不做优惠活动。”应直接出普通文案，不问 ROI。
- “只检查这款第二杯半价是否满足成本。”应在对话里补价格；可回复“单杯售价：18元”。核对资料卡后再继续。
- “单杯成本6.5元，最低贡献5元。”两杯收入应为27元，平均每杯贡献7元；不应询问平台、日期和预算。
- 上传同款同规格价格20元的新资料，应出现18→20元差异；勾选接受后才更新。
- 在品牌与作品管理中打开历史作品，点击“回到对话继续修改”。

活动路径需另外准备经营资料，模板可从附件窗口下载。活动输入示例：

> 主推桂花鲜奶茶，小红书，2026-11-21到2026-11-22含当天，预算200元，预计花费100元，假设160杯，其中20组同单两杯参加第二杯半价，其余原价。请制定活动策略。

这些数字都是测试假设。缺少经营数据时应追问，不应自动填入真实品牌的数据。策略卡出现后须点击确认按钮才生成活动文案。
