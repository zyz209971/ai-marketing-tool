# 茶饮测算口径校准说明（补给赞表）

版本 v0.1｜2026-11-12｜本文档说明「补给赞奶茶店测算表」的口径问题，以及我们校准后的官方口径。

## 一、原表的核心问题

原表把「固定/期间成本」按收入比例摊进了「单杯毛利」，导致三个后果：

1. **「毛利」被污染** —— 原表写「外卖单品毛利 6.53」，但按毛利定义（收入 − 变动成本）应为 9.48。6.53 其实是**净利**。
2. **毛利 vs 净利口径混用** —— 表内「毛利」「净利」两个词的定义前后不一致。
3. **汇总数字对不上单品** —— 「外卖合计 77520」混了扣前/扣后两个口径。

## 二、校准后的口径（铁律）

| 概念 | 定义 | 扣哪些成本 |
|------|------|-----------|
| **变动成本** | 多卖一杯就多花一杯 | 食材 + 包材 +（外卖）平台扣点 |
| **毛利 Gross** | 收入 − 变动成本 | — |
| **期间/固定成本** | 卖不卖都要花 | 人力 + 能耗 + 管理费（按收入分摊）+ 月租金 |
| **净利 Net** | 毛利 − 期间/固定成本 | — |
| **贡献 Contribution** | ≈ 毛利口径 | 用于活动测算：营销投入前/后 |

**关键修复**：固定成本**绝不混进单杯毛利**，只进净利。

## 三、补给赞表复算（校准后）

以「茉莉雪芽轻乳茶」为例（外卖价 18、线下价 16、食材 2.80、包材 1.00、平台扣点 10%、自营销 18%）：

| 指标 | 原表 | 校准后 | 说明 |
|------|------|--------|------|
| 外卖实际收入 | 14.76 | 14.76 | 一致（18 × 0.82） |
| 外卖毛利 | ~~6.53~~ | **9.48** | 原表错标，6.53 实为净利 |
| 外卖净利 | — | **6.53** | 等于原表的「毛利」 |
| 线下毛利 | ~~9.2~~ | **12.20** | 16 − 2.8 − 1.0 = 12.2 |
| 线下净利 | — | **9.00** | 扣分摊固定成本后 |

验证：`14.76 − 2.80 − 1.00 − 1.48 = 9.48` ✅（1.48 = 14.76 × 10% 平台扣点）

## 四、数值规则

- 金额一律用「分」（整数）存储，内部用 `Decimal` 计算，避免浮点误差。
- 比例用百分比整数（10 = 10%）。
- 三态返回：`ok` / `needs_data` / `failed`，绝不补 0 后硬算。
- 单位贡献非正、分母为 0 → 返回「无有效结果」，不输出负保本量、无穷或假 ROI。
