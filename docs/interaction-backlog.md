## 使用说明

1. 新问题放对应优先级分区**最上方**，用下面的模板；
2. 标题格式：`[P1/P2/P3] 一句话标题`，认领后加 `@名字`；
3. 开发按《团队开发指南》第二节回路走：本条目 → Spec Kit 建 spec → 改 → PR（PR 描述里引用本条目）；
4. 合并后回来把标题改成 `[x] 已解决（PR #N）`，正文保留作历史。
