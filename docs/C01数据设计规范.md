## 1. 数据实体总览

围绕 C01 两大能力（经营诊断、活动测算）+ 六个扩展能力，定义 7 类数据实体：

| 实体 | 作用 | 对应能力 |
|------|------|---------|
| product | 商品/SKU 主数据 | 经营诊断、新品测算 |
| ingredient | 配料/加料（配方维度） | 新品毛利测算 |
| sales | 销售订单行 | 经营诊断、活动测算 |
| cost | 成本（分渠道/分配方） | 所有测算 |
| campaign | 营销活动 | 活动测算 |
| constraint | 业务约束 | 保本分析 |
| calendar | 节气/天气日历 | 季节性归因 |

## 2. 字段定义（逐实体）

### 2.1 product（商品/SKU）

| 字段 | 类型 | 说明 | 示例 |

### 2.2 ingredient（配料/加料）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| ingredient_id | string | 配料唯一键 | "IG001" |

## 3. 指标与计算公式

| # | 指标 | 公式 | 依赖字段 |
|---|------|------|---------|
| 1 | 净销量 | `下单数量 − 退款数量` | quantity, refund_quantity |
| 2 | 净销售收入 | `应计销售额 − 商户折扣 − 退款金额`（上游净额则直接用） | gross_amount, merchant_discount, refund_amount, is_upstream_net |
| 3 | 单位贡献 | `单位净收入 − 单位变动成本 − 平台变动费用` | 净收入, ingredient_cost, packing_cost, platform_fee |
| 4 | 活动贡献（前） | `活动净销售收入 − 可归属变动成本` | net_sales, var_cost |
| 5 | 活动贡献（后） | `贡献（前）− 营销投入` | contribution_before, budget |
| 6 | 增量 ROI | `（增量贡献−新增营销投入）÷ 新增营销投入`（需可靠基线） | baseline, incremental_contribution |
| 7 | ROAS | `可归因广告销售收入 ÷ 广告投入` | ad_sales, ad_spend |
| 8 | 保本量/额 | `固定成本 ÷ 单位贡献` / `固定成本 ÷ 毛利率` | fixed_cost, unit_contribution, gross_margin |
| 9 | 毛利率 | `毛利 ÷ 净销售收入 × 100%` | gross, net_sales |
| 10 | 新品毛利（含奶盖） | `新品售价 −（茶底成本 + Σ配料成本）− 平台费` | recipe 各配料 cost |

**新品毛利测算（能力三）专属公式**：

```
新品毛利 = 新品售价 − (茶底成本 + Σ各配料成本) − 平台扣点
毛利率   = 新品毛利 ÷ 新品售价 × 100%

奶盖增益 = 含奶盖配方毛利 − 不含奶盖配方毛利
```

## 4. 数值规则（铁律）

1. **金额一律用「分」整数**存储，内部计算用 Decimal；
2. **比例用百分比整数**（10 = 10%）；
3. **日期带时区**，查询 start 含、end 不含；
4. **退款/折扣只扣一次**，上游净额不重复扣；
5. **三态返回**：ok / needs_data / failed，禁止补 0 后硬算；
6. **无基线不产 ROI**、**贡献非正不产保本**。
