# 合并版前端

采用 frontend-v2 的暖色工作空间布局，接入当前项目的 FastAPI、产品数据库和 RAG。

新克隆仓库不包含本机 `.env` 和数据库；首次运行请先按项目根目录 README 初始化后端与知识库。
迁移及提交分支说明见 `../迁移与提交说明-2026-11-04.md`。

## 使用现有项目启动

在项目的 `backend` 目录，使用你已经安装依赖的 Python 环境运行：

```sh
uvicorn app.main:app --reload
```

打开 http://127.0.0.1:8000/ 。由后端直接提供前端文件；不需要安装 Node.js 或运行前端构建。
旧页面已按要求清理；当前只保留合并版主入口。

现有 `backend/.env` 继续生效，不要覆盖它，也不要将模型密钥写入前端配置。
`src/config.js` 默认 `mode: 'real', apiBaseUrl: ''`，意思是请求当前网页所在服务器。
是否使用真实模型，由后端分别根据文字和图片配置判断。没有相应配置时会明确标示演示结果。

## 页面能力

- 品牌资料、产品管理、JSON 导入、历史作品与表达偏好：保存在当前浏览器。
- 产品添加时输入名称可联想填入；产品库支持显式检索，语义搜索为可选项。
- 营销目的：新品、促销、品牌曝光、节日活动；支持多产品合并或分别生成。
- 平台：小红书、抖音、微信公众号。
- 内容形式：仅文案、图文、仅图片。图文模式先出文案，图片另行点击生成。
- 参考海报：最大 4MB 的 PNG/JPEG/WebP，在请求图片时传给后端视觉解析。
- 文案改写、图片多轮修改、文案与图片版本保存和恢复。
- 应用访问密码与现有访客额度；浏览器取消的是等待，不保证停止后端任务。

## 单独预览或构建

需要 Node.js 20+，无第三方前端依赖。

```sh
npm run dev
```

这只启动静态服务器。真实接口使用前，需在 `src/config.js` 设置 `apiBaseUrl` 为本地后端地址；
否则 `/api/...` 会请求静态服务器而返回 404。直接由 FastAPI 提供页面更省事。

`npm run build` 将文件复制到 `dist`。构建时可用 `.env` 或环境变量设置
`APP_API_MODE=real`、`APP_API_BASE_URL`，后端地址留空表示同源。`npm run preview` 预览构建目录。
独立静态托管需要单独的后端服务，不能仅上传网页就执行模型调用。

## 测试与边界

本次按你的要求只完成代码合并和静态检查，没有执行真实模型、后端或浏览器功能测试。
可自行运行 `npm test`；这些单元测试使用请求替身，不读取后端密钥，也不连接模型。
完整人工检查步骤见项目根目录《前端合并改动说明-2026-11-03.md》。

品牌附件仅记录文件名，产品图片仅作为本地资料，不会自动作为模型图片输入。
本地历史受浏览器存储容量限制，图片和参考海报过大时可能保存失败。
没有新增云端品牌/作品同步、团队账户、自动发布或视频生成功能。

接口详见 `docs/API.md`。
