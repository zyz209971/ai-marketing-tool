文件说明
• CSV 采用 UTF-8。日期为 YYYY-MM-DD，金额单位为元，最多两位小数。分类和活动编号是选填字段。
• 订单每行代表一笔已交付订单中的一种商品规格。去重键为（订单号，商品编号）。
  无优惠或退款填 0，无活动编号时留空。退款前交付数量仍计入销量及成本。
• 菜单的编号、名称、规格、当前售价、卖点、分类逐行对应 products.csv。
  images/P001.jpg 至 images/P005.jpg 为对应商品的 AI 生成示意图。
• 商品名称、规格和卖点参考瑞幸官网。门店、售价、订单、成本、活动和模拟上架日期均为课程合成数据。
• 人工答案 Excel 提供复盘口径及逐日、逐商品对账。expected_answers.json 提供按整数分计算的核对值。
  两天复盘样例的鲜萃轻轻茉莉交付量由 20 杯增至 24 杯，贡献由 230 元降至 168 元，
  扣除 100 元宣传费后，较基线少 162 元。demo_context.json 提供活动与商品来源。

JSON 明细（合成数据）
products.json、orders.json、costs.json 和 campaign_feedback/orders.json 对应同名 CSV。
每个文件是一个记录数组，键名与 CSV 表头一致。日期是 YYYY-MM-DD 字符串，数量是整数，
金额是以元为单位的 JSON 数字。选填项空值用 null，零优惠和零退款仍用 0。
expected_answers.json 的金额字段仍以整数分计。
